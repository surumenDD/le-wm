### モデル規模 (C7)

- Abstract (`paper.cleaned.md:10`): "With ~15M parameters trainable on a single GPU in a few hours, LeWM plans up to 48x faster than foundation-model-based world models"
- Method - Model Architecture (`paper.cleaned.md:106-108`):
    - encoder: Vision Transformer (ViT) tiny, ~5M parameters, patch size 14, 12 layers, 3 heads, hidden 192
    - predictor: transformer 6 layers, 16 heads, 10% dropout, ~10M parameters
- Implementation details (`paper.cleaned.md:555`): encoder は ViT-Tiny (Hugging Face)、predictor は ViT-S backbone と記述される (`paper.cleaned.md:558`)。

### Predictor history length (env 別)

- 出典: `paper.cleaned.md:558` / `source/appendix.tex:311`
- history length = 3 (PushT, OGBench-Cube)、history length = 1 (TwoRoom)

### Ablations: Push-T 上での感度

- Predictor size (`paper.cleaned.md:655-665`): tiny 80.67±6.54、small 96.0±2.83、base 86.7±3.06
- Decoder loss (`paper.cleaned.md:670-681`): w/o decoder 96.0±2.83、with decoder 86.0±7.54
- Encoder architecture (`paper.cleaned.md:687-697`): ViT 96.0±2.83、ResNet-18 94.0±3.27
- Predictor dropout (`paper.cleaned.md:703-717`): p=0.0 78±6.54、p=0.1 96.0±2.83、p=0.2 85.33±5.74、p=0.5 66.67±4.11

### Push-T 訓練条件と CEM 設定

- 出典: `paper.cleaned.md:564`
- CEM: 300 candidates per iteration、最大 30 iterations (Push-T)、その他環境では 10 iterations、top 30 = elites、初期分散 1。
- 計画 horizon = 5 計画ステップ (frame-skip 5 → 25 environment timesteps)。
- MPC: 全 5 ステップを実行した後に再計画 (receding-horizon)。
- frame-skip = 5、batch size 128、sub-trajectory size 4、image 224×224 (`paper.cleaned.md:551-552`)。
