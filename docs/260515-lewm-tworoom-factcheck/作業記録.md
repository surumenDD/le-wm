### 主な発見
- 論文中で TwoRoom 失敗を説明する記述は 4 箇所存在し、3 箇所 (記述 A・B・D) は SIGReg / 表現側に、1 箇所 (記述 C = tab:probe-tworoom キャプション) は「dynamics model または planning procedure itself」側に帰属させる。前者は語尾が "may be explained by" 等で非断定、後者は "the planning gap is **not** due to a less informative representation" と断定形を含む。
- `fig:ctrl-all` の TwoRoom サブパネルでは LeWM = 87、PLDM = 97、DINO-WM = 100、その他のベースライン (GCBC, GCIQL, GCIVL) = 100。LeWM は本図の TwoRoom 評価で最低値。
- LeWM の planning cost は terminal-only な squared L2 距離 ($\mathcal{C}(\hat{\mathbf{z}}_H) = \|\hat{\mathbf{z}}_H - \mathbf{z}_g\|_2^2$, `paper.cleaned.md:157`)。中間ステップでの cost 累積はない。
- 公式 CLAUDE.md で言及される「論文通りの87%」は TwoRoom 環境の LeWM success rate 数値であることが、`figs/ctrl-two-room.pdf` の抽出により確認できた。
