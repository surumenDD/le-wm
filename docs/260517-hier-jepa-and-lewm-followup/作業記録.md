### 主な発見

#### A. ユーザーの記憶 (HIT-JEPA) との照合

- 「HIT-JEPA = Hierarchical Image Transformer JEPA」という記憶は誤り。実在する HiT-JEPA (arXiv:2507.00028, Li et al. 2025) は GPS / 都市軌道の trajectory similarity 用途であり、世界モデルではない。
- ユーザーが言及した「Meta or Mila の hierarchical JEPA」は **HWM (Hierarchical Planning with Latent World Models, arXiv:2604.03208, 2026-04-03)** に該当する。Meta FAIR / NYU / Mila / Brown の共著で、LeCun / Balestriero / Ballas / Bardes など LeWM と重複する著者が含まれる。LeWM の 1 ヶ月後公開。

#### B. LeWM の TwoRoom 87% を直接改善する後続論文が 3 件存在 (2026-05 公開)

| 論文 | TwoRoom 数値 | 改善幅 | 帰属仮説の方向 |
|---|---|---|---|
| RC-aux (2605.07278) | 88.8 → **98.0%** | +9.2pp | 表現 + planning の両軸補助損失 |
| Sub-JEPA (2605.09241) | 84.33 → **95.00%** | +10.7pp | SIGReg を subspace 化 (`260515` 記述 A/B/D 仮説の応答) |
| GC-IDM (2605.08732) | 82.0 → **100%** | +18pp | planning solver の置換 (`260515` 記述 C 仮説の応答) |

3 系統いずれも LeWM 公式実装をそのまま使う形での改善であり、LeWM 公式 87% 再現実験の後段研究として直接接続可能。

#### C. LeWM の方法論的系譜 (Balestriero ライン)

VICReg → Joint Embedding vs Reconstruction (2505.12477, 2025-05) → Gaussian Embeddings (2510.05949, 2025-10) → **LeJEPA / SIGReg (2511.08544, 2025-11)** → **LeWM (2603.19312, 2026-03)** → HWM (2604.03208, 2026-04) と、isotropic Gaussian 正則化系の一直線の系譜が観察できる。

#### D. 著者ネットワーク (両グループの橋渡し)

- **Quentin Le Lidec**: フランスのロボティクス制御コミュニティ (Carpentier / Ponce) と NYU LeCun ラボの構造的接点。LeWM と Value-guided JEPA の両方に共著。
- **Oumayma Bounou**: Value-guided JEPA + Temporal Straightening (2603.12231, Balestriero 共著, 2026-03-12) の双方に名を連ね、Le Lidec とは異なるルートでの橋渡し。
- **Maes / Scieur / Balestriero のトリオ**: 2025-Q3 (UniReps) から 2026-Q1 の stable-worldmodel-v1 / LeWM / Causal-JEPA まで、半年で 5 本以上の共著。

#### E. 著者本人による LeWM の姉妹論文

- **stable-worldmodel-v1 (2602.08968, 2026-02)**: LeWM 公式 codebase の母艦ライブラリ。TwoRoom を含む 17 個の factor of variation。
- **Causal-JEPA (2602.11389, 2026-02)**: object-level latent intervention で counterfactual reasoning を VQA で +20pp 改善。
- **LeJEPA (2511.08544, 2025-11)**: SIGReg の提案論文。LeWM の損失設計の心臓部。
