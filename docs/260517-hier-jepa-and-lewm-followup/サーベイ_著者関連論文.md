エグゼクティブサマリー (主要 3 本、LeWM SIGReg の系譜):
- **Gaussian Embeddings (2510.05949)**: JEPA の anti-collapse 項がデータ密度を推定していることを証明。閉形式の JEPA-SCORE を提案し I-JEPA / DINOv2 / MetaCLIP で検証。
- **LeJEPA (2511.08544)**: 「isotropic Gaussian が JEPA embedding の最適分布」を証明し、それを強制する SIGReg を提案。stop-gradient / teacher-student / EMA / scheduler 不要、約 50 行で実装可。ViT-H/14 で ImageNet-1K linear probe 79%。
- **Reward-Free Offline (2502.14819 = PLDM)**: JEPA で latent dynamics model を学習し planning に利用。未見レイアウトへの一般化とデータ効率で model-free RL を凌駕。LeWM の TwoRoom 評価設定の母艦。

LeWM の方法論的系譜 (Balestriero ラインのみで):
VICReg (旧来) → Joint Embedding vs Reconstruction (2505.12477) → Gaussian Embeddings (2510.05949) → **LeJEPA / SIGReg (2511.08544)** → **LeWM (2603.19312)** → HWM (2604.03208)

- **Closing the Train-Test Gap (2512.09929)**: world model は next state 予測で訓練されるが planning 時には action 列推定に流用される、というギャップを **train-time data synthesis** で埋める。CEM 並み or 超の成績を 10% の計算時間で達成。gradient-based planning + JEPA 系 world model の改善。
- **Temporal Straightening (2603.12231)**: 人間視覚に着想を得た curvature regularizer で latent trajectory を直線化し、Euclidean 距離が測地距離をよく近似するよう encoder / predictor を訓練。**Bounou が両グループの橋渡し位置** にあることを示す論文。
