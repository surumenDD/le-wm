本ファイルの内容は、論文 2601.00844 本文・LeWM 論文本文・既存 docs の事実を組み合わせた「現状ではエビデンスを持たない計画」である。したがって本ファイル内では:

- 推測 (実験せずには照合できない事項、論文 2601.00844 の wall 環境と LeWM の TwoRoom 環境の同一性に依存する事項、ハイパラ移転の効果、表現側 vs planning 側の切り分けに関する仮説) を `### 現在検討中の点` に集約する。
- 確定した運用 / 実験方針 (= 私の許可を得て確定した方針) があれば `### 採用方針` に記載する。本ファイル作成時点では `### 採用方針` は空 (= 確定方針なし)。

## 事実

### 事実 1: 両論文の手法の関係

- 論文 2601.00844 は、JEPA モデルの状態エンコーダを「(quasi-)Euclidean 距離 ≈ 負の目標条件付き価値関数 $V^\star$」となるよう IQL 損失 $\mathcal{L}_\text{VF}$ で学習する手法を提案する (出典: `論文のエビデンスベースの知見_提案手法.md` §IQL loss for JEPA)。
- LeWM (2603.19312v2) の状態エンコーダは MSE 予測損失 $\mathcal{L}_\text{pred}$ と SIGReg (Sketched Isotropic Gaussian Regularizer) の和 $\mathcal{L}_\text{LeWM} = \mathcal{L}_\text{pred} + \lambda \cdot \text{SIGReg}(\mathbf{Z})$ で学習される (出典: `docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_Planning手法.md` §訓練側)。
- LeWM の planning cost は終端のみで評価される squared L2 距離 $\mathcal{C}(\hat{\mathbf{z}}_H) = \|\hat{\mathbf{z}}_H - \mathbf{z}_g\|_2^2$ (出典: `docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_Planning手法.md` §planning cost の定義)。
- 論文 2601.00844 は planning cost を「学習された価値関数 $V_\theta$ に設定して最小化する」と本文 §3 で述べる (`論文のエビデンスベースの知見_提案手法.md` §推論手順)。具体的な数式形は本論文中で MPPI 設定として記述される範囲に留まる。
- 両論文とも MPC ベースの planning solver を採用する。LeWM は CEM、論文 2601.00844 は MPPI (出典: 各論文の Implementation details)。

### 事実 2: LeWM TwoRoom 失敗に関する論文内記述の現状

- LeWM 論文中で TwoRoom 環境における LeWM の planning gap (LeWM 87% vs PLDM 97% vs DINO-WM 100%) を説明する記述は本文 / 図キャプション / 付録テーブルキャプション / Conclusion の 4 箇所に存在する (出典: `docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_TwoRoom帰属.md` §記述 A〜D)。
- 4 箇所のうち 3 箇所 (記述 A, B, D) は SIGReg / representation 側に帰属させ、1 箇所 (記述 C = tab:probe-tworoom のキャプション) は representation の問題では「ない」と否定して dynamics model または planning procedure 側に帰属させる。
- tab:probe-tworoom の数値では、LeWM と PLDM の probing (agent の 2D 位置) は MLP MSE / Linear r いずれもほぼ同値 (LeWM: Linear MSE 0.008±0.018, MLP MSE 0.000±0.000; PLDM: Linear MSE 0.008±0.041, MLP MSE 0.000±0.000、出典: `論文のエビデンスベースの知見_数値表.md` §TwoRoom probing)。
- すなわち LeWM 論文側のエビデンスは、TwoRoom の representation が PLDM と同等の物理状態情報量を持つことを示すと同時に、representation 側に planning gap の原因を帰属させる別記述も含むという、内部での記述の不整合を残している。

### 事実 3: 環境構成の対応 (LeWM TwoRoom vs 論文 2601.00844 wall)

- LeWM TwoRoom (`docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_TwoRoom環境.md`):
    - 出典文献: `[sobal2025stresstesting]`。
    - 2 部屋を 1 つのドアで連結した連続 2D ナビゲーション。
    - データ: 10,000 episodes、平均軌跡長 92 steps、heuristic policy (ドア向け → ターゲット向け)。
    - 訓練 epoch: 10。観測サイズは LeWM 共通の 224×224 (frame-skip 5)。
    - predictor history length = 1 (他環境 = 3)。
    - 評価予算 = 150 steps、goal は 100 timesteps 先からサンプリング。
- 論文 2601.00844 wall (`論文のエビデンスベースの知見_実験設定と結果.md` §wall 環境):
    - 出典文献: `[sobal2025learningrewardfreeofflinedata]` (PLDM 論文)。
    - 壁とドアで分割された正方形空間、壁とドア位置はランダム初期化。
    - データ: 1000 軌道 × 長さ 64、半数がドア通過。観測サイズ 64×64、2 チャネル。
    - WS / WB は行動ノルム分布のみ異なる。
    - planning horizon WS=96 / WB=64、計画ステップ数 WS=200 / WB=64。
- 両環境とも「壁・ドアで分割された 2 部屋ナビゲーション」という構造は共通だが、出典文献・データ規模 (10,000 vs 1000 trajectory)・観測サイズ (224 vs 64)・壁とドアのランダム化方針が異なる。LeWM 論文と 2601.00844 論文の双方とも、同名の論文に対して別の wall 系環境を引用している。

### 事実 4: ハイパーパラメータ転移可能性に関する論文側の記述

- 論文 2601.00844 は $\gamma = 0.98, \tau = 0.80$ (VF) と $\gamma = 0.93, \tau = 0.60$ (VF\_quasi) を採用するが、これは WS 環境上での最適化結果である (`論文のエビデンスベースの知見_実験設定と結果.md` §IQL ハイパーパラメータ)。
- 同論文 §Discussion は、$\tau$ を $1$ に近づけると性能が向上するが、$1$ に近すぎると不安定性が出るとし、$\tau$ / $\gamma$ は環境固有の最適化対象である旨を示す (`paper.cleaned.md:157`)。
- LeWM TwoRoom データセットへ同論文のハイパラを直接適用する場合、再最適化なしで同等の planning 改善が得られるかは本論文中に記述なし。

### 事実 5: 「IQL + 別損失」併用に関する論文側の結果

- 論文 2601.00844 §Results の table tab:results (`論文のエビデンスベースの知見_実験設定と結果.md` §Table 2) は、以下の数値を報告する:

| 設定 | WS | WB | Maze |
|---|---|---|---|
| VF (Sep, IQL only) | 0.63 | 0.94 | 0.49 |
| VF\_pred (joint with $\mathcal{L}_\text{pred}$) | 0.55 | 0.75 | 0.49 |
| VF\_VCReg (with $\mathcal{L}_\text{VCReg}$) | 0.49 | 0.75 | 0.39 |
| VF\_VCReg\_pred | 0.47 | 0.67 | 0.39 |
| VF\_quasi (Sep, IQL+quasi) | 0.71 | 0.96 | 0.63 |

- IQL に「予測損失」または「VCReg」を加えると planning accuracy が低下するという結果が 3 環境で観察された (本論文の解釈、`paper.cleaned.md:91`)。
- ただし上記の VCReg と LeWM の SIGReg は別の正則化 (VCReg は分散・共分散ベース、SIGReg は等方ガウス整合)。SIGReg + $\mathcal{L}_\text{VF}$ の挙動は本論文の VCReg + $\mathcal{L}_\text{VF}$ から直接外挿することはできない。

## 現在検討中の点

### 検討点 A: 導入の構成パターン

LeWM に論文 2601.00844 の手法を導入する場合の候補構成は複数あり、いずれも本論文や LeWM 論文の実験ではカバーされていないため、エビデンスは現時点で存在しない。

#### A-1. Planning cost のみ置換 (post-hoc)

- 構成: LeWM 既存の `encoder + predictor + SIGReg` の学習はそのまま、planning 時の cost を $V_\phi(\hat{\mathbf{z}}_H, \mathbf{z}_g) = -\Vert f_\phi(\hat{\mathbf{z}}_H) - f_\phi(\mathbf{z}_g) \Vert_2$ (もしくは quasimetric 版) に置換する。$f_\phi$ は LeWM の latent から別空間へ写像する小規模 MLP / projection head として学習。
- 学習方針: $f_\phi$ を IQL 損失 $\mathcal{L}_\text{VF}$ で別途学習。LeWM 本体は凍結。
- 既存 docs との関係: `論文のエビデンスベースの知見_TwoRoom帰属.md` §記述 C 「planning gap は representation 側ではなく dynamics or planning procedure 側」という帰属仮説に対する検証 (= planning cost のみ変更して TwoRoom 87% が改善するか) として使える。
- 未確認事項: LeWM の latent が SIGReg により等方ガウスに整形されている上で、その上に IQL の expectile regression を適用しても TD ターゲットの学習がうまく進むかは不明。
- 未確認事項: 論文 2601.00844 では encoder 自体を IQL で再構成しているため、frozen latent 上で projection head のみを IQL 学習する設定は同論文の実験範囲外。

#### A-2. Encoder 全体を $\mathcal{L}_\text{VF}$ で再学習 (Sep に倣う)

- 構成: LeWM の状態エンコーダを SIGReg を外して $\mathcal{L}_\text{VF}$ のみで学習し、その後 predictor を $\mathcal{L}_\text{pred}$ で学習。論文 2601.00844 の Sep モードに対応。
- 既存 docs との関係: `論文のエビデンスベースの知見_TwoRoom帰属.md` §記述 A, B, D 「TwoRoom 失敗 ← SIGReg と低 intrinsic dim の不整合」という帰属仮説に対する検証 (= SIGReg を $\mathcal{L}_\text{VF}$ に置換して TwoRoom 87% が改善するか) として使える。
- 未確認事項: LeWM の encoder (ViT-Tiny, 5M params) は論文 2601.00844 の encoder (conv+residual, 2.2M params) より大きく、表現次元も異なる (ViT-Tiny hidden 192 vs 論文 2601.00844 flat 512)。同論文の anti-collapse 議論は VCReg / EMA に基づいており、$\mathcal{L}_\text{VF}$ 単独で ViT を学習した場合の collapse 挙動は本論文中に記述なし。
- 未確認事項: LeWM の predictor (ViT-S, 10M params, history length 1 for TwoRoom) に対して状態エンコーダを別途事前学習する場合、predictor の学習が成立するかは未検証。論文 2601.00844 は predictor を MLP (1.3M params) とし、predictor history を扱わない設計。

#### A-3. SIGReg + $\mathcal{L}_\text{VF}$ の joint training

- 構成: $\mathcal{L}_\text{LeWM-VF} = \mathcal{L}_\text{pred} + \lambda \cdot \text{SIGReg}(\mathbf{Z}) + \mu \cdot \mathcal{L}_\text{VF}$ として状態エンコーダ + 予測器を同時学習。
- 既存 docs との関係: 記述 A/B/D と記述 C のどちらが planning gap の主因かを切り分けず、両側に同時に介入する設定。
- 関連事実: 論文 2601.00844 では VF + $\mathcal{L}_\text{pred}$ の joint (VF\_pred) は VF 単独より planning accuracy が低い (3 環境で観察、本文の解釈、`論文のエビデンスベースの知見_実験設定と結果.md` §Table 2)。さらに VF + VCReg は VF 単独より低い (同表)。
- 未確認事項: 論文 2601.00844 の VCReg + VF の結果が SIGReg + VF にどの程度外挿できるかは不明 (VCReg と SIGReg は別の正則化)。

### 検討点 B: 環境同一性

- `論文のエビデンスベースの知見_実験設定と結果.md` §wall 環境と `docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_TwoRoom環境.md` を突き合わせると、両者は「壁とドアで分割された 2D ナビゲーション」という構造を共有するが、出典文献・データ規模・観測サイズが異なる (本ファイル §事実 3)。
- LeWM 論文の TwoRoom データセットを論文 2601.00844 の wall (WS / WB) の代理として使う場合、データ規模 (10,000 vs 1000 trajectory) と観測サイズ (224 vs 64) の差を埋める必要がある。本タスクでは差を埋めず、LeWM 論文の TwoRoom データセットをそのまま使う前提で検討を進める。
- 仮にデータセットを共通化 (= LeWM の TwoRoom データを 2601.00844 のモデル規模に合わせて 64×64 / 1000 trajectory にダウンサンプル) すれば、2601.00844 の VF / VF\_quasi の数値が LeWM TwoRoom と直接比較可能になるかも未確認。

### 検討点 C: リサーチクエスチョン候補

`260515-lewm-tworoom-factcheck` ブランチで残された未解明事項 (`docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_TwoRoom帰属.md` §現在検討中、`docs/260515-lewm-tworoom-factcheck/作業記録.md` §残課題) に対して、本論文 2601.00844 の手法を導入することで照合可能となりうる設問を列挙する。各設問は本タスクでは推測の範囲に留め、実験的検証は本タスクの範囲外。

- **RQ1.** TwoRoom 環境において LeWM の planning cost (squared L2) を $V_\theta$ ベースのコストに置換した場合、LeWM TwoRoom 87% は変化するか。変化方向は何か (改善 / 悪化 / 不変)。
    - 照合する元の未解明事項: 記述 C の「planning gap は dynamics model または planning procedure itself」帰属仮説。
    - 実験設計: 検討点 A-1。LeWM 本体凍結 + planning cost のみ変更。LeWM 既存の TwoRoom 評価プロトコル (eval budget 150, goal 100 timesteps 先) で planning accuracy を計測。
- **RQ2.** TwoRoom 環境において LeWM の状態エンコーダを SIGReg なしの $\mathcal{L}_\text{VF}$ で再学習 (Sep) した場合、TwoRoom 87% は変化するか。
    - 照合する元の未解明事項: 記述 A, B, D の「TwoRoom 失敗 ← SIGReg と低 intrinsic dim の不整合」帰属仮説。
    - 実験設計: 検討点 A-2。Encoder を $\mathcal{L}_\text{VF}$ のみで学習、predictor は別途 $\mathcal{L}_\text{pred}$ で学習。
- **RQ3.** SIGReg と $\mathcal{L}_\text{VF}$ を joint で学習した場合 (A-3) の挙動は、論文 2601.00844 の「VF + VCReg は VF 単独より低い」結果と同様の傾向を示すか。
    - 照合する元の未解明事項: SIGReg と VCReg の挙動的差異。
    - 実験設計: 検討点 A-3。
- **RQ4.** quasimetric 版 (VF\_quasi) は LeWM の TwoRoom 環境においても VF 単独より高い planning accuracy をもたらすか。
    - 照合する元の本論文 2601.00844 の現象: 「VF\_quasi が VF を一貫して上回る」(3 環境で観察、本論文の解釈、`論文のエビデンスベースの知見_実験設定と結果.md` §Table 2)。
    - 実験設計: A-1 / A-2 のいずれか or 両方で、$V_\theta$ の距離関数を Euclidean / quasimetric の 2 通りで比較。
- **RQ5.** 論文 2601.00844 の Discussion §Locality of the training で示される「遠い状態三つ組のスパースサンプリング」「目標から遠い状態での勾配減衰」が、LeWM の TwoRoom 設定 (eval budget 150, goal 100 timesteps 先) でどの程度問題化するか。
    - 照合する元の未解明事項: TwoRoom の「100 timesteps 先 goal」(`docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_TwoRoom環境.md` §評価条件) が IQL の locality 問題を顕在化させるかどうか。
    - 実験設計: TD-target の学習曲線、value error の (start–goal) 距離別の評価 (probing 風)。
- **RQ6.** 論文 2601.00844 の $\gamma, \tau$ を LeWM TwoRoom データセットに適用する場合、再最適化が必要か。
    - 照合する元の本論文 2601.00844 の記述: 「$\tau$ が $1$ に近すぎると不安定」(`paper.cleaned.md:157`)、データセット差による再最適化の必要性 (本論文の Discussion `paper.cleaned.md:97`)。
    - 実験設計: 同論文と同じ手順 ($\tau, \gamma$ 1D sweep) を別 WS 上で再走 → TwoRoom 上で planning accuracy を測定。

### 検討点 D: 環境上の制約 (本タスクでは扱わない事項)

- 論文 2601.00844 は決定論的環境のみで評価しており、`paper.cleaned.md:105` で「IQL approach is known to be biased in random environments」と記述する。LeWM の TwoRoom は決定論的 (heuristic policy で軌跡生成) なので、本論文の決定論的制約と矛盾しない。
- LeWM の他の評価環境 (PushT, OGBench-Cube, Reacher) は本タスクの範囲外。これらに対する $\mathcal{L}_\text{VF}$ 導入の挙動は別タスクで扱う。

### 検討点 E: 実装上の確認事項

- LeWM 公式コード (https://github.com/lucas-maes/le-wm) に CEM ベースの planning solver と $\mathcal{L}_\text{pred} + \lambda \cdot \text{SIGReg}$ の学習ループが実装されている (`docs/260515-lewm-tworoom-factcheck/論文のエビデンスベースの知見_Planning手法.md` §訓練ハードウェア・実装)。$\mathcal{L}_\text{VF}$ の導入には以下が必要となるが、いずれも本タスクの範囲外:
    - expectile loss $L_\tau^2(x) = |\tau - \mathbf{1}_{x<0}| \, x^2$ の実装。
    - stop-gradient ターゲット $V_{\bar{\theta}}$ の管理 (target encoder の EMA or 周期的コピー)。
    - 目標サンプリング (軌跡末端 + ランダムバッチ) の dataloader 改修。
    - quasimetric の generic form (`[wang2022improved]` 由来) の実装。
- 論文 2601.00844 の公開コードリンクは本論文中で確認できなかった (本タスク内で再度確認の余地あり、`papers/2601.00844_value_guided_action_planning_with_jepa_w/extraction_report.md` 等)。
