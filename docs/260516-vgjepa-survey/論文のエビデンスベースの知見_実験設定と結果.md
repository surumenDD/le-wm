# 論文のエビデンスベースの知見: 実験設定と結果

論文 `Value-guided action planning with JEPA world models` (Destrade et al., arXiv:2601.00844v1) の実験設定および定量結果を、出典付きで整理する。

---

## 事実

### 環境構成

- 出典: 本文 §4.1 (`paper.cleaned.md:65-71`, `source/Results.tex:5-9`)、付録 §A.1 (`paper.cleaned.md:115-135`, `source/main.tex:103-165`)

#### wall 環境

- 仕様 (`paper.cleaned.md:69`, `paper.cleaned.md:121`):
    - 観測サイズ: $64 \times 64$、2 チャネル (1 チャネルがエージェント、1 チャネルが壁)。
    - 1 つのドアを持つ壁で分割された正方形空間。壁とドアの位置は環境インスタンス化時にランダム。
    - 行動: 変位 (displacement) を表すベクトル。
    - エージェントは開始位置から壁の反対側のランダムな目標へ移動する。
- 軌道生成 (`paper.cleaned.md:125`):
    - 行動方向はランダム方向に集中度 $\kappa = 5$ の von Mises 分布ノイズを加える。
    - 軌道数: 1000、軌道長: 64、うち半数がドアを通過する軌道。
- WS / WB の差 (行動ノルム分布、`paper.cleaned.md:127`):

| データセット | 行動ノルム平均 | 行動ノルム std | クリッピング範囲 |
|---|---|---|---|
| WS | 1 pixel | 0.4 | $[0.2, 1.8]$ |
| WB | 2 pixels | 0.8 | $[0.4, 3.6]$ |

#### maze 環境

- 仕様 (`paper.cleaned.md:71`, `paper.cleaned.md:131`):
    - 観測サイズ: $64 \times 64$、3 チャネル (カラー)。
    - Mujoco PointMaze 環境 (`[fu2021d4rldatasetsdeepdatadriven]`) に基づく。
    - $4 \times 4$ マスのグリッドで、$50\%$–$60\%$ の連続マスを選択して迷路を形成。
    - 行動: 速度指令 (target speeds)。慣性をシミュレートするため、状態に速度を含めてエンコーダに渡す。
- 軌道生成 (`paper.cleaned.md:133`):
    - 速度ベクトル (ノルム $< 5$) をランダム位置からサンプリング。
    - 軌道数: 1000、軌道長: 101。
    - 評価時、開始点と目標は少なくとも 3 マス離れた位置からサンプリング。
- 訓練 / 評価分離 (`paper.cleaned.md:135`):
    - 訓練軌道は 5 つの迷路レイアウトに属し、評価レイアウトとは異なる。

### モデル構成 (encoder / predictor / action encoder)

- 出典: 付録 §A.2 (`paper.cleaned.md:143-145`, `source/main.tex:170-176`)
- アーキテクチャ:
    - 表現次元: 512 (flat)。
    - 状態エンコーダ: 畳み込み + 残差接続、2.2M parameters。
    - 予測器: MLP、1.3M parameters。
    - 行動エンコーダ: 恒等写像 (identity)。
    - 予測器入力: 状態表現と行動表現の concatenation。
- 訓練設定:
    - 入力軌道のサブサンプリング: 長さ 16 のセグメント。
    - 基本学習率: 0.0028、Adam optimizer、cosine schedule。
    - wall 環境: VCReg は batch 次元のみで計算。
    - maze 環境: VCReg は batch + 時間次元の両方で計算。

### planning 時の MPPI 設定

- 出典: `paper.cleaned.md:145`, `source/main.tex:174`

| 環境 | サンプル数 | サンプリング std | 温度 $\lambda$ | planning horizon | 計画ステップ数 |
|---|---|---|---|---|---|
| WS | 2000 | 12 | 0.005 | 96 | 200 |
| WB | 2000 | 12 | 0.005 | 64 | 64 |
| Maze | 500 | 5 | 0.0025 | 100 | 200 |

- 「planning horizon = 96」「総計画ステップ数 = 200」など、horizon と総ステップ数が分離されている点に注意 (= horizon は 1 回の計画あたりの先読み長、計画ステップ数は環境内で実行する全ステップ数)。本論文中では `K`-step replanning や receding horizon の具体的記述は本文では明示されていないが、horizon ≠ total step の構成から MPC の反復が含意される。

### IQL ハイパーパラメータ

- 出典: `paper.cleaned.md:147`, `source/main.tex:176`

| 設定 | $\gamma$ | $\tau$ |
|---|---|---|
| VF-based | 0.98 | 0.80 |
| VF\_quasi-based | 0.93 | 0.60 |

- 値の選定根拠: 別の WS データセットで $\gamma, \tau$ を最適化した結果 (詳細は付録 §Addexp `paper.cleaned.md:151-157`)。
- 付録の方針記述 (`paper.cleaned.md:157`):

> Increasing $\gamma$ improves performance, as it better captures the relationships between distant states. The same applies to $\tau$, which should theoretically be set as close to $1$ as possible. However, setting either parameter too close to $1$ introduces instabilities that degrade performance.

### 評価指標

- 出典: `paper.cleaned.md:83`, `source/Results.tex:66`
- planning accuracy = 「(開始状態, 目標) のランダム対に対する成功計画の割合」。
- 評価サンプル数: wall = 200 instance、maze = 80 instance (`paper.cleaned.md:83`)。
- 「結果の分散を小さくするためのサンプル数」と本文に記述あり。

### 結果に関する論文側の記述

- 出典: `paper.cleaned.md:89-91`, `source/Results.tex:118-120`
- 原文 1:

> They show that IQL-inspired approaches provide valuable guidance during planning and achieve better results than intuitive or prediction-based approaches, as used in [sobal2025learningrewardfreeofflinedata]. Interestingly, the VF\_quasi approach consistently outperforms the VF approach, even when the theoretical value function is symmetric. This suggests that using a quasi-distance always facilitates the training process by enhancing the expressiveness of the networks.

- 原文 2 (続き):

> Learning representations using both a prediction loss and an IQL loss is less effective than using the latter loss alone. Using VCReg to promote diversity when learning with an IQL loss also results in poor planning performance. The results obtained with the WB dataset are better than those obtained with the WS dataset. This may be due to the fact that a single trajectory explores more of the environment in the WB dataset, and that the agent is more likely to collide with the wall.

- 著者が記述する観察:
    - IQL 系 (VF, VF\_quasi) は intuitive / prediction-based より高い planning accuracy。
    - VF\_quasi は VF を一貫して上回る (理論的に対称な価値関数の場合でも)。
    - $\mathcal{L}_\text{pred}$ と $\mathcal{L}_\text{VF}$ の同時学習 (= `*_pred` 行) は、$\mathcal{L}_\text{VF}$ 単独より低い planning accuracy。
    - VCReg を IQL に加えると planning accuracy が低下。
    - WB > WS の関係について、論文側は「WB では単一軌道がより広範囲を探索し、壁衝突が起きやすい」ことを「may be due to」と推定的に説明。

### 追加実験: 予測表現と planning 表現の分離

- 出典: `paper.cleaned.md:159`, `source/main.tex:204` (および LaTeX コメントアウトされた古い数値の上書き `source/main.tex:80`)
- 原文:

> One might hypothesize that representations learned using a prediction loss yield better prediction accuracy, while those learned with an IQL approach result in a more effective planning cost. It is possible to combine the advantages of both by adopting an intermediate approach. In this approach, two separate representation spaces are learned: the first with a standard prediction loss, and the second with an IQL loss using a second state encoder. During planning, the first level is used to compute predictions, and the second level to compute the cost. We tested this method with the WS dataset using the pred\_VCReg approach for the first level and the VF approach for the second level. It did not improve planning results, with a planning accuracy of $0.60$.

- 第 1 階層: pred\_VCReg (予測損失 + VCReg) で学習。
- 第 2 階層: VF (IQL 損失) で別の状態エンコーダを学習。
- 計画時: 第 1 階層で predict、第 2 階層で cost 計算。
- 結果: WS で planning accuracy 0.60 (= 表 2 の VF\_pred 0.55 や pred\_VCReg 0.55 を上回るが、VF 単独 0.63 / VF\_quasi 0.71 を下回る)。

## 現在検討中の点

- 本論文中で wall / maze 環境の intrinsic dimensionality を定量測定した値は確認できなかった。
- $\mathcal{L}_\text{pred}$ の具体的な数式形 (squared L2 か否か、$\hat{z}_{t+1}$ と $z_{t+1}$ の正確な定義) は本論文の本文中に明示式は確認できなかった。先行研究 `[sobal2025learningrewardfreeofflinedata]` (PLDM) のコードベースに準拠することが本論文では示唆されるのみ。
- 「VF\_quasi が VF を上回る」現象を理論側で説明する記述は本文中に確認できなかった (本文の説明は "facilitates the training process by enhancing the expressiveness of the networks" のみ)。
- planning 時の cost が「$V_\theta(\hat{z}_H, z_g)$ を最大化 (= 距離を最小化)」と書かれるべき箇所について、本論文中で planning cost の数式は明示されていない (`paper.cleaned.md:38` の "setting the planning cost to the learned value function" という記述に留まる)。先行研究 `[sobal2025learningrewardfreeofflinedata]` の MPPI 実装に依拠することが推察されるが、それは推測の範囲。
- 評価が決定論的環境のみで行われている (Discussion `paper.cleaned.md:105` に「random environments での実験は将来の課題」と記述あり) ため、確率的環境への一般化に関する直接的な実験的根拠は本論文中に存在しない。
