## 作業の位置づけ
論文 `Value-guided action planning with JEPA world models` (Destrade et al., arXiv:2601.00844v1, World Modeling Workshop 2026 poster) のアルゴリズム・提案手法をエビデンスベースで整理する調査タスク。

加えて、本論文の手法を LeWorldModel (arXiv:2603.19312v2、以下 LeWM) に導入する場合の構成を、別途 `推測作業プラン.md` に切り出して整理する。事実 docs と推測 docs を明確に分離し、論文 2601.00844 単独で照合可能な事項のみを `論文のエビデンスベースの知見_*.md` に記載する。

実装・訓練は本タスクの範囲外。事実整理と導入想定の整理のみを成果物とする。
