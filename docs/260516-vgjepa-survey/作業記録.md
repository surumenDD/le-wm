### 主な発見 (事実ベース)

- 論文 2601.00844 は JEPA の状態エンコーダを IQL 損失 $\mathcal{L}_\text{VF}$ で学習し、$V_\theta(s, g) = -\Vert \mathcal{E}_\theta(s) - \mathcal{E}_\theta(g) \Vert_2$ が目標条件付き価値関数 $V^\star$ を近似するように表現空間を整形する。
- planning solver は MPC + MPPI。planning 時 cost を「学習された価値関数」に設定する旨が本文 §3 に明記される (具体数式は本論文中に明示なし、MPPI 設定として記述されるのみ)。
- Table 2 の planning accuracy では VF\_quasi が WS=0.71 / WB=0.96 / Maze=0.63 で 3 環境とも最大値。「IQL + 予測損失 / IQL + VCReg」は IQL 単独より低いという結果を 3 環境で観察。
- LeWM TwoRoom と論文 2601.00844 の wall (WS/WB) は同じ「壁・ドア付き 2D ナビ」構造を持つが、出典文献・データ規模・観測サイズが異なる (本タスクの推測 docs §事実 3)。

### 主な発見 (推測ベース、`推測作業プラン.md` 側に集約)

- LeWM TwoRoom の planning gap 帰属について、論文 2601.00844 の手法を導入することで「representation 側 (記述 A/B/D)」と「dynamics or planning procedure 側 (記述 C)」のどちらが主因かを切り分け可能となりうる設問を RQ1–RQ6 として整理。
- 構成 A-1 (planning cost のみ置換) は記述 C 仮説の検証、A-2 (encoder 全体を $\mathcal{L}_\text{VF}$ で再学習) は記述 A/B/D 仮説の検証に対応する。
- 論文 2601.00844 の Discussion §Locality of the training は、目標から遠い状態での価値関数勾配減衰を指摘する。LeWM TwoRoom の評価条件 (eval budget 150 steps, goal 100 timesteps 先) はこの問題が顕在化しうる長さの設定 (本タスクでは推測の範囲)。
