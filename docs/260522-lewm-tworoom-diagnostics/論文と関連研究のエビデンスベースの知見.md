# 論文と関連研究のエビデンスベースの知見

### 事実

- LeWorldModel 論文は、raw pixels から end-to-end に学習する JEPA world model として LeWM を提示し、loss は next-embedding prediction loss と Gaussian-distributed latent embeddings を強制する regularizer の2項であると述べている。出典: arXiv `2603.19312` abstract, https://arxiv.org/abs/2603.19312 。
- LeWorldModel 論文は、Two-Room で LeWM が他手法より低い性能を示す説明として、低い data diversity と低い intrinsic dimensionality により、high-dimensional latent space で SIGReg の isotropic Gaussian prior に encoder が一致しにくいことを挙げている。出典: `2603.19312_leworldmodel/source/sections/4-exp.tex:22`。
- LeWorldModel 論文の Fig. `ctrl-all` caption は、Two-Room では PLDM と DINO-WM が LeWM を上回ること、SIGReg が high-dimensional latent space で Gaussian distribution を促す一方で environment の intrinsic dimensionality が低いことを説明として挙げている。出典: `2603.19312_leworldmodel/source/sections/4-exp.tex:56`、`2603.19312_leworldmodel/source/sections/4-exp.tex:58`。
- LeWorldModel 論文は physical latent probing として linear probe と non-linear probe を使い、MSE と Pearson correlation coefficient を報告している。出典: `2603.19312_leworldmodel/source/appendix.tex:354`、`2603.19312_leworldmodel/source/appendix.tex:356`、`2603.19312_leworldmodel/source/appendix.tex:358`。
- LeWorldModel 論文の TwoRoom probing は agent の 2D position を対象にしている。出典: `2603.19312_leworldmodel/source/appendix.tex:360`。
- LeWorldModel 論文の TwoRoom probing table では、LeWM の Linear MSE は `0.008 ± 0.018`、Linear r は `0.996`、MLP MSE は `0.000 ± 0.000`、MLP r は `1.000` と報告されている。出典: `2603.19312_leworldmodel/source/appendix.tex:371`、`2603.19312_leworldmodel/source/appendix.tex:376`。
- LeWorldModel 論文の TwoRoom probing table caption は、TwoRoom の planning gap は representation の情報量不足ではなく dynamics model または planning procedure 側の要因であると述べている。出典: `2603.19312_leworldmodel/source/appendix.tex:364`。
- LeWorldModel 論文は decoder を訓練時には使わず、診断用に latent embedding から画像を復元する decoder visualization を報告している。出典: `2603.19312_leworldmodel/source/sections/4-exp.tex:114`、`2603.19312_leworldmodel/source/sections/4-exp.tex:120`、`2603.19312_leworldmodel/source/sections/4-exp.tex:121`、`2603.19312_leworldmodel/source/sections/4-exp.tex:133`、`2603.19312_leworldmodel/source/sections/4-exp.tex:134`。
- LeWorldModel 論文は temporal latent path straightening として consecutive latent velocity vectors の cosine similarity を測定している。出典: `2603.19312_leworldmodel/source/sections/4-exp.tex:138`。
- RC-aux 論文は、short-horizon prediction が正確でも latent space が planning と整合しない場合があること、local predictive supervision と long-horizon goal-directed search の spatiotemporal mismatch を課題として述べている。出典: arXiv `2605.07278` abstract, https://arxiv.org/abs/2605.07278 。
- RC-aux 論文は、time axis では multi-horizon open-loop prediction、space axis では budget-conditioned reachability supervision と temporal hard negatives を追加すると述べている。出典: arXiv `2605.07278` abstract, https://arxiv.org/abs/2605.07278 。
- RC-aux 論文は LeWorldModel 上で RC-aux を実装し、continuation-training と matched-from-scratch の両設定で評価したと述べている。出典: arXiv `2605.07278` abstract, https://arxiv.org/abs/2605.07278 。
- Sub-JEPA 論文は、LeWM の isotropic Gaussian prior が collapse を緩和する一方で、latent representations が high-dimensional ambient space 内の low-dimensional manifolds にあるため、ambient space に直接 isotropic Gaussian prior を課すことが強い bias を導入すると述べている。出典: arXiv `2605.09241` abstract, https://arxiv.org/abs/2605.09241 。
- Sub-JEPA 論文は、original embedding space ではなく multiple random subspaces に Gaussian constraints を適用すると述べている。出典: arXiv `2605.09241` abstract, https://arxiv.org/abs/2605.09241 。
- GC-IDM 論文は、pretrained LeWorldModel の latent geometry を対象に、iterative planning を Goal-Conditioned Inverse Dynamics Model で置き換えると述べている。出典: arXiv `2605.08732` abstract, https://arxiv.org/abs/2605.08732 。
- GC-IDM 論文は、current latent state、goal latent state、remaining horizon を入力として next action を直接出力する軽量モデルを使うと述べている。出典: arXiv `2605.08732` abstract, https://arxiv.org/abs/2605.08732 。

### 現在検討中の点

- LeWorldModel 論文内には TwoRoom の room ID や goal までの相対位置を probe した表は確認できていない。
- LeWorldModel 論文内には TwoRoom の effective rank または intrinsic dimension を数値として報告した箇所は確認できていない。
- Sub-JEPA の effective rank 解析は、arXiv abstract だけでは詳細な数式・評価条件を確認できていない。
- RC-aux の reachability supervision は、本研究の `b: 潜在距離と到達可能性の対応` と `d: planner cost の整合性` の両方に関係するため、実験単位の切り分けが未確定である。
- GC-IDM は planner を置き換える研究であり、現行 CEM cost の診断と直接比較するか、別枠の control head として扱うかは未確定である。

### 採用方針

- `a: 表現情報量` の初期指標は、Linear probe MSE、MLP probe MSE、Pearson r、R2、linear と MLP の差分、effective rank とする。
- TwoRoom の probe target は、論文再現として agent 2D position から開始する。room ID と goal までの相対位置は dataset 列定義と goal sampling の確認後に追加する。
- `b: 潜在距離と到達可能性の対応` では、latent Euclidean distance と shortest-path distance、same-room/cross-room、door passage requirement、finite-budget reachability label の対応を記録する。
- `c: multi-step dynamics の精度` では、teacher-forced one-step prediction と open-loop multi-step rollout を分けて記録する。
- `d: planner cost の整合性` では、現行 terminal latent MSE cost と success、physical final distance、path feasibility、reachability label の対応を記録する。
